# WebGL проект

## Опис
Це проект, що використовує WebGL для рендерингу графіки у браузері. Він дозволяє налаштовувати кольори фону, розміри канви та інші параметри для створення інтерактивної графіки.

## Налаштування

### 1. Підготовка розмітки
Перед тим, як розпочати роботу з проектом, необхідно додати базову HTML-розмітку:

```html
<div class="anim-container">
  <canvas class="canvas" id="canvas"></canvas>
</div>
```
### 2. Ініціалізація

Для початку необхідно мати налаштований WebGL контекст. Якщо ви використовуєте цей проект, просто переконайтеся, що ваш браузер підтримує WebGL. 

Перевірте це таким чином:

```javascript
const canvas = document.querySelector('#canvas');
const gl = canvas.getContext('webgl');

if (!gl) {
  console.error('WebGL не підтримується!');
}
```
