### 2. **README для налаштувань кольору:**

Якщо ти хочеш мати окремий файл для налаштувань кольору, ось приклад того, як це
можна організувати:

````markdown
# Налаштування кольору

Цей файл пояснює, як можна налаштувати колір фону та інші параметри кольору в
проекті.

## Формати кольорів

1. **HEX**: Наприклад, `#ff5733`.
2. **RGB**: Наприклад, `rgb(255, 87, 51)`.
3. **RGBA**: Наприклад, `rgba(255, 87, 51, 0.5)`.

### Приклади використання

1. Для встановлення червоного фону:
   ```javascript
   clearScene(gl, '#ff5733');
   ```
````
